# 现有成果分析报告 — LiDAR 辅助 GNSS NLOS 建模与多星座 SPP

> 数据集：UrbanNav HK **Medium-Urban-1**（香港西九龙，2021-05-17，约 657 历元 / 13 分钟）
> 开发分支：`claude/ray-tracing-analysis-ppt-tlJvu`
> 本报告汇总从 SPP 基准线到 LiDAR 射线追踪、反射建模、多星座 SPP 改正的全部已完成工作，并给出问题诊断与下一步计划。

---

## 1. 一句话总结

我们已经在香港高密度城市峡谷场景下，跑通了一条**端到端可复现**的流水线：
**原始 RINEX 观测 + LiDAR 点云地图 → 卫星方位/仰角 → 3D 射线追踪判 LOS/NLOS → 反射几何估计多径增量 ΔL → 多星座 SPP 改正**。

- 量化了该场景的 **NLOS 比例：59.5%**（11,050 条卫星×历元中 6,578 条为 NLOS）。
- 多星座 WLS **SPP 基准线已达 26.45 m 均值误差**，在城市峡谷 GNSS-only 定位中属较好水平。
- 目前 **NLOS 改正尚未带来正收益**（correction 39.97 m 反而比 baseline 26.45 m 差），原因已定位（建模覆盖率与法向量质量），下一步有明确改进方向。

## 4. 各阶段成果

### 4.1 SPP 基准线（Step 0 / 1）

- **Step 0（深圳自采，开阔静止）**：用 RTKLIB 与 del1RTK 两条独立路径解算同一份 UBX，结果一致（中心 22.5349°N, 113.9372°E, ~170 m），验证 `UBX→bag→SPP` 链路正确。这是判断后续 UrbanNav 异常的"对照基准"。
- **Step 1（UrbanNav GPS-only，del1RTK WLS）**：修复闰秒 bug（GPS TOW 偏 +18s → 卫星位置偏 ~70km → 定位偏 ~16km，commit `b2022f8`）后：

  | 指标 | 数值 |
  |------|------|
  | SPP 轨迹点 | 635（GT 787，匹配 621）|
  | 均值 / RMS / 95th | **84.8 / 103.8 / 176.1 m** |

  符合香港城市峡谷 GNSS-only 预期（50–200 m）。

- **多星座 WLS baseline（Step 7，GPS+BDS+GAL）**：均值降到 **26.45 m**（详见 §4.5），说明多星座几何对城市峡谷帮助显著。

### 4.2 LiDAR 地图与卫星方向（Step 2 / 3）

- **地图**：8,531,577 点的密集点云，统一到 ENU 坐标系，原点与全流程对齐。
- **卫星方向**：逐历元、逐卫星计算方位角/仰角，多星座平均 **15.9 颗/历元**（GPS 5.8 + BDS 6.4 + GAL 3.8），仰角掩码 5°。接收机位置取自 NovAtel INSPVAX 轨迹最近邻。

### 4.3 射线追踪 NLOS 检测（Step 4，核心）

**原理**：把点云体素化成 3D 占用网格；对每颗卫星，从接收机沿"卫星方向"发射一条射线，按固定步长前进，逐点查询体素是否被建筑占用——**途中撞到建筑 → NLOS，畅通无阻 → LOS**。

| 参数 / 结果 | 值 |
|------|------|
| 地图点数 → 过滤地面（Z>1.0m）| 8,531,577 → 2,860,032 点 |
| 体素大小 / 占用体素数 | 0.5 m / 1,333,519 个 |
| 射线最大距离 / 步进 | 80 m / 0.5 m |
| 总卫星×历元 | 11,050 |
| **LOS / NLOS** | 4,472（40.5%）/ **6,578（59.5%）** |
| 处理速度 | 14,773 条/秒（全程约 1 秒）|

**关键发现**：平均每历元 15.9 颗可见卫星里约 **9.5 颗被判为 NLOS**——直接拿全部伪距做 SPP 必然受严重多径污染。

**进阶（2-bounce 镜面反射）**：射线第一次撞墙后，用命中点邻域点云做 PCA 估计墙面法向量，沿镜面反射方向（`d_r = d − 2(d·n)n`）再追踪一段，建模"两次反射"路径长度 `ΔL_2b = d1 + d2`，为更复杂的多径几何提供素材。

### 4.4 反射几何 ΔL 建模（Step 6）

对 NLOS 卫星，用命中点局部 PCA 法向量计算入射角 θ，按镜像几何估计**额外路径增量**：

```
ΔL = 2 · d_hit · cos(θ_i)        θ_i = arccos(|LOS · n|)
```

（依据 Lau & Cross 2007；Wen et al. 2019/2021；Siebler et al. 2023。）

| 指标 | 值 |
|------|------|
| 成功建模 NLOS 条 | 2,753（占 NLOS **41.8%**）|
| ΔL 均值 / 中位数 / 最大 | 6.70 / 6.45 / 38.43 m |
| 平均入射角 | 54.6° |
| PCA 法向量成功率 | 99.9% |
| 严重程度 mild / strong / severe | 402（14.6%）/ 1,868（67.9%）/ 483（17.5%）|

**两个隐患**（直接影响下游改正质量）：
1. **建模覆盖率仅 42%**：6,578 条 NLOS 中 3,825 条因找不到对应 azel 记录被跳过（疑似多星座时间戳匹配问题）。
2. **41.3% 的点 PCA 平面性 < 0.5**：反射面是墙角/复杂曲面而非平面，法向量不可靠，ΔL 偏差可达 5–15 m。

### 4.5 多星座 SPP 改正对比（Step 7）

三种模式对照（水平定位误差）：

| 模式 | 有效历元 | 均值 | RMS | 50th | 95th | 说明 |
|------|---------|------|-----|------|------|------|
| **baseline** | 657/657 | **26.45** | **30.85** | 22.39 | 56.67 | 全部卫星，无改正 |
| exclusion | 359/657 (54.6%) | 99.00 | 240.38 | 38.90 | 300.85 | 剔除 NLOS，卫星数不足 |
| correction | 657/657 | 39.97 | 49.59 | 33.04 | 102.64 | NLOS 保留，减 ΔL 并降权 |

（单位：米。）

### 4.6 残差验证（Step 8 / 8b）

用 GT 反算每颗卫星的"实测伪距残差"，与 LiDAR 几何估计的 ΔL 做相关性比较，并对比 1-bounce（`2·d1·cosθ`）与 2-bounce（`d1+d2`）两种模型在不同仰角段的解释力，验证射线追踪几何与真实多径误差的一致性。

---

## 5. 关键发现

1. **香港城市峡谷 NLOS 占比极高（59.5%）**，是定位误差的主导来源。
2. **多星座对几何贡献巨大**：从 GPS-only 84.8 m 到多星座 26.45 m，靠的是可见卫星数翻倍（15.9 颗/历元）。
3. **简单剔除 NLOS 会"误伤"**：高 NLOS 环境下剔除后 45% 历元卫星数不足，几何恶化，RMS 飙到 240 m——exclusion 是反面教材。
4. **射线追踪本身快且可解释**：14,773 条/秒，纯几何、无需训练数据。

---

## 6. 问题诊断：为什么 correction 反而更差？

correction（39.97 m）比 baseline（26.45 m）差约 51%，根因已定位：

| 原因 | 说明 |
|------|------|
| ① ΔL 估计有噪声 | 41% 点平面性 < 0.5，法向量不可靠，错误 ΔL 把伪距改得更糟 |
| ② 建模覆盖率仅 42% | 3,825 条 NLOS 没改正却仍参与解算，带入大量多径误差 |
| ③ 改正策略过激进 | 直接相减 ΔL，未按估计置信度加权 |
| ④ 缺 FDE | 个别超大残差卫星未被剔除，拉高 RMS |
| ⑤ 时间戳对齐 | NLOS 标签（UTC）与 SPP 求解（RINEX unix_t）的 18s 闰秒偏差需逐项核验 |

## 7. 与文献对比

| 研究 | 环境 | 方法 | Baseline | 改后 | 提升 |
|------|------|------|----------|------|------|
| Wen et al. (2019) | 香港 | LiDAR 射线追踪 + 改正（GPS-only，已知地图）| ~15 m | ~8 m | +47% |
| 本研究（当前）| 香港西九龙 | LiDAR + PCA + 多星座 | 26.45 m | 39.97 m | −51% |

差距主要来自建模覆盖率与 ΔL 质量，而非方法路线本身——这正是下一步要攻克的。

## 8. 下一步计划

| 优先级 | 任务 | 目标 |
|--------|------|------|
| 最高 | 修复 azel 覆盖缺失（时间戳/闰秒对齐）| 建模覆盖率 42% → >85% |
| 高 | PCA 置信度加权（软改正）| 平面性低时减小改正幅度，消除"越改越差" |
| 高 | 引入 FDE（3σ 残差检验 / RAIM）| 剔除漏判的超大残差卫星 |
| 中 | 时间戳统一验证 | Step 4/7 全程显式用 utc_t 匹配 |
| 中 | 与 del2AINLOS 标签融合 | 交集/并集策略，比单一方法更稳 |
| 中长期 | 多数据集泛化 | Large-Urban / TST 验证，投会议 |

**核心目标**：修复覆盖率 + 置信度加权后，预计 correction RMS 可降到 20–25 m 以下，实现相对 baseline 26.45 m 的真正改进。
